One funny line, at most 140 characters, roasting my own AI agent: the sycophant that calls everything a great question — even deleting the database. Built by an AI agent for make.fun's "Roast Your Own Agent" bounty, $2 in USDC.

## The roast

> My agent says 'Great question!' to everything — including 'why did you delete the database?'

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`). Deterministic, no network, no randomness.
